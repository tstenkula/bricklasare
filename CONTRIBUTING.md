# Issues and suggestions

Brickläsaren is a Tobtech project. Reports and proposals are welcome through
GitHub Issues. Describe the platform, app version, reader model and reproducible
steps. Do not include real card numbers, reader profiles, private keys, tokens,
personal branding or information about an actual access installation.

Code is available for inspection under [LICENSE.txt](LICENSE.txt). Personal use
is free; commercial and organizational use requires a paid written license from
Tobtech. This project is not open source. Proposed code contributions are subject
to section 4 of the license. Changes enter official releases only after review
and validation. A public fork does not grant general redistribution rights.
